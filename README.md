# 🛒 Walmart Black Friday Analysis

## 📌 Objective
To analyze customer purchase behavior during Black Friday and determine 
whether spending patterns differ across Gender, Age, and Marital Status 
using Central Limit Theorem (CLT) and Confidence Intervals.

---

## 📊 Project Structure

1. Basic Metrics Analysis
2. Non-Graphical Analysis
3. Visual Analysis (Univariate & Bivariate)
4. Missing Value & Outlier Detection
5. CLT & Confidence Intervals
6. Final Insights & Business Recommendations

---

## 🛠 Tools Used
- Python
- Pandas
- NumPy
- Seaborn
- Matplotlib
- SciPy

---

## 📈 Key Insights
- Purchase distribution is right-skewed.
- CLT normalizes sampling distribution.
- Gender-based spending shows statistically significant difference.
- Age group 26–45 contributes highest revenue.
- City B & C show strong high-value transaction patterns.
